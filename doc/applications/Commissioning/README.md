# Commissioning

The Commissioning application exercises ZumoComSystem peripherals for hardware bring-up. It displays button and LED activity, reports battery readings and tests the robot stream and reset line. It runs without a robot or network infrastructure.

PlatformIO environment: `CommissioningTarget`.
